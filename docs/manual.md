# 使用手冊

這份文件寫給**使用者**，不是開發者。想知道程式怎麼組起來的，看
[architecture.md](architecture.md)。

---

## 這個 App 在做什麼

一句話：**用你自己的字典和教材，加上你已經有的 AI 訂閱，長出一套只屬於你的語言學習迴圈。**

拆開來是四件事：

1. **背單字**，用 FSRS 演算法排間隔（跟 Anki 同一個家族，但參數更現代）
2. **讀程度剛好的文章**，AI 依你目前會的字現場生一篇，難度控制在「九成看得懂」
3. **做翻譯與文法練習**，答錯的地方會回頭變成複習卡
4. **只從你的課本出題**，匯入電子書之後，AI 不准講課本以外的東西

全部離線運作。唯一連網的時候是你叫 AI 出題，而那也可以走你本機的
`claude` 或 `codex` 指令，不必另外開 API 帳單。

## 第一次使用

### 1. 匯入字典（必要）

Wordforge **不內建任何字典資料**。好用的字典幾乎都有版權，散布出去是侵權，
所以第一步是你自己取得一份。

開啟 App 之後會有引導告訴你去哪裡拿。學英文的話，這兩份最實用：

```bash
# ECDICT：中文翻譯、音標、詞頻，還有國中會考／學測／多益等考試範圍標籤
curl -LO https://raw.githubusercontent.com/skywind3000/ECDICT/master/ecdict.csv
wordforge import ecdict ecdict.csv

# Wiktionary：英文定義、例句、詞形變化表、發音（3.2 GB，可以之後再補）
wget https://kaikki.org/dictionary/English/kaikki.org-dictionary-English.jsonl
wordforge import kaikki kaikki.org-dictionary-English.jsonl
```

只想先跑起來的話，ECDICT 一份就夠。兩份可以並存，同一個字會同時顯示兩邊的釋義。

**學其他語言**：到 [kaikki.org](https://kaikki.org/) 找你要的語言，下載 JSONL
之後從「匯入」頁載入，或用 `wordforge import kaikki <檔案> --lang <代碼>`。
記得到「設定 → 學習語言」把目標語言改成對應的代碼，否則查字典跟出題會對不上。

> 幾百 MB 以上的檔案建議用命令列匯入。GUI 也能做，但把幾 GB 的檔案丟給
> 視窗程式並不合適，而且命令列看得到進度。

### 2. 做分級測驗（建議）

到「牌組」頁按分級測驗。它會從不同詞頻區間抽字問你認不認識，估出你的詞彙量。

意義是：**已經會的字不會再排給你**。學過幾年英文的人不必從 the、go、make 重來。

### 3. 加單字進牌組

同樣在「牌組」頁，按考試範圍挑：國中會考、學測、多益、雅思、牛津核心⋯⋯
選一個範圍加進去就可以開始背。

也可以開「自動補充」——牌組裡沒學過的字少於 100 個時自動補上，
不必每隔幾天回來手動加。

### 4. 設定 AI（想用 AI 出題才需要）

到「設定 → AI 後端」。如果你這台機器裝了 Claude Code 或 Codex CLI，
它會自動偵測到，選一個就好，**不必再開一份 API 帳單**。

沒有訂閱的話也可以填 API 金鑰，或指向本機的 Ollama。

## 每天怎麼用

### 複習

「複習」頁一次一張卡：看字 → 想意思 → 按空白鍵看答案 → 誠實評分。

| 按鍵 | 意思 |
| --- | --- |
| `空白` | 顯示答案 |
| `1` | 忘記了 |
| `2` | 有點難 |
| `3` | 記得 |
| `4` | 很簡單 |
| `B` | 跳過今天（明天自己回來，排程不受影響） |
| `S` | 收起這張（要到牌組頁主動恢復） |

**評分要誠實**。FSRS 是照你的實際表現算間隔的，虛報「記得」只會讓那個字
在你真的忘掉之後才回來。

**跳過與收起不算答錯**。按 `B` 是「今天不想看到這張」，按 `S` 是
「這張根本不該出現」，兩個都不會影響排程。

### 練習

「練習」頁按程度出題：

| 題型 | 需要的詞彙量 | 在做什麼 |
| --- | --- | --- |
| 目標語翻母語 | 0 | 給一個句子，寫出中文 |
| 母語翻目標語 | 100 | 給一個中文句子，寫出目標語 |
| 克漏字 | 300 | 短文挖空 |
| 文法練習 | 300 | 針對你犯過的錯出題 |
| 閱讀測驗 | 1,500 | 一篇文章加四題理解題 |

選「自動」的話系統會挑，並且避開你上一題剛做過的題型。

閱讀測驗的文章會**刻意放進幾個你還不會的字**——那是 90% 法則的重點，
一篇全部看得懂的文章讀完學不到東西。挑的是詞頻剛好在你程度上緣的字
（比你會的再難一點，但還在會再遇到的範圍），而且會**湊出不同詞性**：
全是名詞的話句型不會有變化，動詞尤其重要。

**批改之後最重要的事**：AI 會判斷你哪些字其實不會，那些字**自動變成複習卡**。
你不必自己判斷哪裡不懂——從錯誤裡看出來本來就是老師的工作。

閱讀測驗時可以**點文章裡的任何一個字**標記「我不會」，那些字也會一起進牌組。

批改結果下面會有**文章解析**：文章裡的生字與片語，附字典釋義。
那一段不是 AI 寫的，是拿文章去查你匯入的字典得到的——所以它不會編造。

## 只從我的課本出題

到「設定 → 教材」匯入你的課本，支援：

| 格式 | 備註 |
| --- | --- |
| 純文字 `.txt` `.md` | |
| EPUB | |
| PDF | **只讀得到文字層**。掃描的書沒有文字層，要先做 OCR |
| 字幕 `.srt` `.vtt` | 時間軸會自動去掉 |
| HTML | |

命令列也可以：

```bash
wordforge material add 課本.pdf --lang en --title "國中英文 第一冊" \
    --license-note "自己買的，不外流"
wordforge material list
```

匯入之後，「練習」頁會多出一個「取材範圍」下拉選單。選了課本之後，
AI 出的題目**只能用那本書的主題、情境與用字**，不准引入課本以外的知識點。

教材清單上會顯示「你已掌握 N%」——這本課本的字你會了幾成。

> App **不散布任何教材**。`--license-note` 那一欄是給你自己記的，
> 提醒自己這份東西能不能分享出去。

## 設定

### 學習語言

**我要學**的選項來自你匯入了哪些字典。想學清單上沒有的語言，去匯入那個語言的字典。

**用這個語言解釋**是你的母語，決定字義翻譯、批改講評、文法說明用什麼語言寫。

換語言時舊牌組不會自動處理，但會告訴你還有幾張別的語言的卡片，
可以一鍵收起來（是收起來不是刪除，換回去時複習歷史都還在）。

### 每日份量

| 設定 | 說明 |
| --- | --- |
| 每天引入新字 | 15 張大約每天 10 分鐘。設 50 的話三週後每天複習量會超過一小時 |
| 每天最多複習 | 放假幾天回來不會一打開就看到七百張 |
| 目標留存率 | 90% 是平衡點。調高不是「學得更好」，而是拿更多複習時間換更少的遺忘 |

做完今天的份還想學的話，複習頁會給你「再學 10 個」的按鈕。

### AI 模型與推理強度

「設定 → AI 後端」可以挑模型和推理強度，兩個都有下拉選單，
也都可以選「自訂…」自己打（清單會隨各家改版過期）。

**推理強度是這裡最大的旋鈕，差距比換模型還大。** 實測一題閱讀測驗
（codex，同一份 prompt）：

| 模型 | 強度 | 耗時 |
| --- | --- | --- |
| gpt-5.6-luna | `high` | 111 秒 |
| gpt-5.6-luna | `medium`（預設） | **43～65 秒** |
| gpt-5.5 | `medium` | 31 秒 |
| gpt-5.5 | `low` | 21 秒 |

覺得等太久就往下調。要注意的是**「快」跟「題目好不好」不是同一件事**，
而後者程式量不出來——本地能驗的只有生詞覆蓋率，上面四種設定算出來
都是 99% 以上（都偏簡單）。所以這個選擇最後還是要你自己讀了才知道。

`gpt-5.6-luna` 需要 codex-cli 0.147 以上。

**模型清單一定會過期。** 兩個 CLI 都沒有可以查詢模型清單的指令，
所以那份下拉選單沒辦法自動更新。選「自訂…」可以自己打，
按**「試跑這個模型」**會實際送一個最小 prompt 過去——成敗就是答案，
而且不會過期。

選了新型號卻不能用，通常是 CLI 版本太舊（`requires a newer version of
Codex`），試跑的結果會直接告訴你要跑 `codex update`。

### AI 用量

顯示今天與近七天的呼叫次數與字元數。

**為什麼是字元數不是 token**：拿不拿得到 token 取決於後端。HTTP API 的回應裡
就有用量，但 `claude -p` 與 `codex exec` 的輸出只有內容，沒有用量資訊。
把字元數乘個係數謊報成 token 只會讓你做出錯誤判斷。後端真的有回報時會另外顯示。

## 資料存在哪裡

| 平台 | 路徑 |
| --- | --- |
| Linux | `~/.local/share/org.wordforge.app/` |
| macOS | `~/Library/Application Support/org.wordforge.app/` |
| Windows | `%APPDATA%\org.wordforge.app\` |

`wordforge.db` 一個檔案裝下所有東西：字典、牌組、複習歷史、教材、練習紀錄。
**備份就是複製這個檔案。**

API 金鑰**不在**資料庫裡，另外存成權限 600 的檔案。理由是資料庫很可能被
複製到雲端硬碟，金鑰不該跟著跑。

## 常見問題

**說我今天做完了，但「今日複習」是 0？**
可能是分級測驗把卡片收起來了。複習頁的空狀態會告訴你實際原因，
並給對應的按鈕（恢復被收起的卡／再學幾個新字）。

**牌組頁是空的？**
字典還沒匯入。先去「匯入」頁載一份。

**AI 出的文章太難？**
系統本來就會在本地實算覆蓋率，不到九成會要求重寫。如果還是覺得難，
通常是分級測驗高估了你的詞彙量——重做一次測驗即可。

**設定頁說 codex／claude「未安裝」，但終端機裡明明能跑？**
從應用程式選單啟動的程式拿到的是系統的最小 `PATH`，看不到 nvm、asdf
這類版本管理器加的路徑——而 `claude` 與 `codex` 都是 Node 程式。
App 會自己去問你的 shell 要完整的 `PATH`，所以正常情況下偵測得到。
還是不行的話，從終端機啟動 App 一定可以。

**發音是機器音？**
預設用系統語音合成。到「設定」頁下載真人錄音（來自 Wiktionary），
之後會優先播放真人版本。

**可以同步到手機嗎？**
沒有雲端同步伺服器，也不打算做（要營運就要收錢）。
把資料目錄放進你自己的雲端硬碟資料夾是可行的做法，但**不要兩台同時開**，
SQLite 不喜歡那樣。

**AI 會知道我的哪些資料？**
出題時送出去的是：你的詞彙量估計、60 個已知詞的抽樣、今天到期的字、
最近犯錯的 5 個文法點、一個情境主題。批改時再加上你的答案。
不會送出你的完整牌組——那會讓 prompt 大到失控。

## 命令列

```bash
wordforge path                      # 資料庫在哪
wordforge stats                     # 字典規模與來源
wordforge search <字>               # 查一個字
wordforge import <格式> <檔案>       # 匯入字典或詞頻表
wordforge deck tags                 # 有哪些考試範圍標籤
wordforge deck add <標籤> --limit N # 依標籤加單字
wordforge material add <檔案> --lang <代碼>
wordforge material list
```

每個指令都有 `--help`。
