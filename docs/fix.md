# 閱讀測驗
- 問題應該是使用英文問(有時會有中文的問題)
- 最後解析應該提供完整的文章翻譯
- 閱讀測驗的文字大小應該要可以調整
- 文章在左邊，解析在右邊比較好看
- 解析不要把所有的文字翻譯都輸出，我認為可以像標記看不懂得單字那樣點擊出現單字或是片語翻譯
- 答案應該分散不應該規律在某個選項
- 給出題 llm 的 prompt 要加上一個題目出完後需要檢查文章是否通順
- 出題的難度應該要有不同等級，不能全難或是全簡單

# 練習
- 練習的紀錄應該留存
- llm生成的時候如果點到其他地方就會中斷
- 可以用紀錄重複練習並讓llm批改
- 出下一題的時候需要把前面的練習清掉
- 出題的時候我覺得要加入轉圈動畫

# 翻譯
- 中翻英與英翻中的題目都是中文的，prompt 應該要限制輸出格式

# 其他
- 在設定新增一個重製按鈕可以重製整個使用者資料與練習，要有確認按鈕以防誤觸
